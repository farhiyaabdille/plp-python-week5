# PLP Python Week 5

This repository contains my Python Week 5 assignment on loops.

- `countdown.py` asks for a starting number and counts down to “Blast off!” with a while loop.
- `guess_game.py` runs a number guessing game with high/low hints and an attempt counter.
- `spell_it_out.py` prints a word letter by letter, then prints numbered letters and the total length.
- `screenshots/` contains screenshots showing each program running.

I would reach for a `while` loop when I need to repeat an action until a condition changes or an event happens, especially when I do not know the number of repetitions in advance. I would use a `for` loop when I need to process every item in a sequence or repeat a known number of times.
